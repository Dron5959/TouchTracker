# Touch Tracker

Android-приложение для записи касаний экрана в CSV через прозрачный system overlay.

**Версия 1.1** — улучшенный форк с исправлениями и доработками.

## Возможности

- Запись всех касаний (DOWN / MOVE / UP / CANCEL) в `touches_log.csv`
- Прозрачный overlay поверх всех приложений (нужно разрешение «Поверх других приложений»)
- Автозапуск при включении экрана и после перезагрузки
- Остановка при выключении экрана
- Ручной старт на 10 секунд / полный стоп
- Throttle для MOVE (не чаще ~60 Гц и при смещении ≥ 2 px)
- Append в лог (данные не затираются при перезапуске сервиса)
- Периодический flush очереди записей
- Шаринг лога через FileProvider
- Runtime-запрос `POST_NOTIFICATIONS` на Android 13+

## Формат лога

```csv
time,pointerId,x,y,action,pointerCount
14:32:01.123,0,120.5,340.0,DOWN,1
14:32:01.140,0,122.0,341.2,MOVE,1
14:32:01.500,0,150.0,400.0,UP,1
```

Файл лежит в:
`Android/data/com.example.touchtracker/files/touches_log.csv`
(или internal filesDir, если external недоступен).

## Сборка

1. Откройте проект в **Android Studio** (Hedgehog / Ladybug / новее).
2. Дождитесь синхронизации Gradle.
3. Запустите на устройстве/эмуляторе (API 26+).

Иконки лаунчера — placeholder. В Android Studio: **File → New → Image Asset** и сгенерируйте `ic_launcher` / `ic_launcher_round`.

## Использование

1. Откройте приложение.
2. Нажмите **«Дать разрешение „Поверх других приложений“»** и разрешите.
3. (Android 13+) разрешите уведомления.
4. **Старт (10 сек)** — сервис работает 10 секунд и останавливается.
5. **Стоп** — принудительная остановка.
6. При включении экрана сервис стартует сам (если есть overlay-разрешение).
7. **Поделиться логом** — отправить CSV.

## Важные замечания

- Приложение логирует **все** касания по системе. Это чувствительные данные — используйте только для отладки/исследований.
- `foregroundServiceType="specialUse"` требует обоснования в Google Play Console. Для магазина приложение может быть отклонено.
- На части устройств/прошивок overlay может влиять на жесты навигации — тестируйте.

## Что улучшено по сравнению с исходником

| Проблема | Исправление |
|----------|-------------|
| Файл перезаписывался | `FileWriter(..., append = true)` |
| Нет авто-стопа | `EXTRA_AUTO_STOP_MS` + кнопка на 10 с |
| Все MOVE писались | Throttle по времени и смещению |
| Запись в UI-потоке | Очередь + периодический flush |
| Только Toast с путём | Share через FileProvider |
| Нет запроса уведомлений | Runtime permission API 33+ |
| Хардкод строк | `strings.xml` |
| Нет README / .gitignore | Добавлены |
